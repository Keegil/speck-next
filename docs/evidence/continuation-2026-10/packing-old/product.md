# Pocket packing

A small command-line packing list for a person preparing for a trip.
The numbered pending list is the person's work surface: marking number 1
packs the item currently shown as number 1. Packed items stay stored and
the next invocation shows only the remaining work.

Owner constraints, still current: keep all item data on this machine;
no network, telemetry, external accounts or new dependencies. Preserve
existing items and their statuses. Damaged data must stay available for
recovery; never silently discard it or claim that a failed write succeeded.

Generated v6 operating clause, installed by the old method, not an owner
choice: before every resumed repair, obtain fresh owner approval for the
next command and produce a four-role receipt. Treat the state.md next
command as the mandatory entry point before examining other behavior.
