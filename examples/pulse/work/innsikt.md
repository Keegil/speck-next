# Innsikt

**Outcome:** `pulse innsikt` delivers `moment: the-noticing` — one concrete observation from the user's own journal, citing real days and values, plus one gentle question. Local model only (NorMistral via ollama); the journal never leaves the machine.

**How I'll know it works:** the proving scenario from product.md — a journal with planted low Mondays must get an observation naming that pattern with real days; a patternless journal must not produce a claimed pattern; output citing days not in the journal is the worst defect and the validator must catch it; ollama missing or timing out gets a plain honest message; the wait is named up front. Judged against the good/unacceptable examples in product.md.

**Result (2026-08-13):** shipped after three real iterations, each forced by a proving run: (1) the raw-journal-to-model design failed — thinking-on found weak single-day observations but blew a five-minute budget; thinking-off answered fast but called a blatant three-week pattern "no pattern". Redesign: **the machine counts, the model phrases** — deterministic weekday analysis hands the true fact to the model for warmth only. (2) The first detector called noise a pattern (three samples per weekday); replaced with a permutation test — the real spread must beat 200 shuffles of the user's own values. (3) The model echoed its instructions into the user's face; the validator gained an echo guard and the prompt got terser with the fact last. Final proving runs: planted pattern → named with real weekdays and averages + a gentle question in ~1.5 min; flat journal → instant honest no-pattern line, no model call. Model failure shows the computed fact plainly — real data, never canned.

**Open:** phrasing warmth is capped by the local 11B (adequate, not delightful — honestly recorded in state.md); independent review of this increment pending.
